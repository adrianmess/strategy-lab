Feature definitions

OB bid/ask depth imbalance at ±1% and ±2%, plus spread · CVD true aggressor-signed cumulative delta, slope and divergence vs price · VP rolling POC and value-area edges from tick volume at traded prices · OI open-interest change over N bars, long/short ratio, funding skew.

Sync

schedule
Binance daily zips are appended, features recomputed for the new day, engine caches cleared through update_data.py — the same rule as candles.

Guards

A run outside a feature's history is refused, not zero-filled. Features are joined by timestamp with a 1-bar lag so nothing looks ahead. Funding is charged at each 8h boundary a position is open, from MEXC's own rate.
