flowx neworder-flow momentum

CVD slope + book imbalance must agree with price before entry; exits on CVD divergence. Uses OBCVD, optional OI filter.

poctrend newvalue-area pullbacks

Trend filter, entries on pullbacks to the rolling POC / value-area edge, targets at the opposite edge. Uses VP, optional CVD confirmation.

oisqueeze newpositioning breakouts

OI build-up during price compression → breakout in the direction the book leans; funding skew as a contrarian filter. Uses OIOB.

absorb newabsorption reversals

Heavy CVD against price with no follow-through (the book absorbing) → fade. Uses CVDOBVP.
Each new family gets the same treatment as the bases: searched per pair (HYPE, SOL, XRP, SUI, DOGE), at honest fees, through the same holdouts — and its own feature-ablation row in the matrix so we know which inputs it actually depends on.
