Builds are resumable (already-built days are skipped) and run as panel jobs (~2 s per day per coin). Binance book depth exists from 2024-05-17 for SOL/XRP/DOGE, 2024-09-13 for SUI and 2025-05-30 for HYPE — the frames cannot reach further back whatever the candle history. Funding is charged from the first MEXC settlement on file; earlier bars carry zero.

    

  

    
Feature definitions

      OB bid/ask notional imbalance (bid−ask)/(bid+ask) at ±1%, ±2% and ±5% of mid (Binance bookDepth, ~30 s snapshots, last per bar). Gate: gObMin at level gObLvl.

      CVD aggressor-signed cumulative volume delta from aggTrades; the gate uses its change over gCvdLen bars as a rolling z-score ≥ gCvdZ.

      VP rolling volume-profile point of control over 120/300/600 minutes (fixed 5 bp bins) plus the 70 % value area; gate: price beyond POC by gVpDist.

      OI open interest (5-min metrics): change over 30 m / 1 h / 4 h ≥ gOiChg in direction gOiDir.

      FUNDING MEXC 8-hour rate × position notional at each settlement a perp trade spans — a cost, never a signal.

    
Guards
A search is refused when the pair/timeframe has no feature frame; bars outside coverage never enter (the run is clipped, never zero-filled). Features are joined by bar start and read at bar close, like every indicator. Enriched runs stamp features / funding / base_run on their config and every published backtest, and a backtest pins the same feature set the search used. Classic runs are untouched: with no features enabled every engine is byte-identical to before.

    
Sync
Frames are built on the MacBook or the mini with enriched_features.py build and live in research/features/ (copied between machines with the campaign sync). Extend a frame by re-running build with the same since: new days are appended, per-tf frames re-assembled, and the manifest updated. Engine caches are not affected — features attach on load and are never pickled.
